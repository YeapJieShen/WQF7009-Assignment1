# Contributing

This is a solo coursework repository for WQF7009 Explainable Artificial Intelligence.

## Workflow

1. Branch off `main`:
   - `feat/taskN-short-name` for assignment tasks
   - `fix/short-name` for bug fixes
   - `chore/short-name` for tooling, docs, and housekeeping
2. Commit in small, focused steps using [Conventional Commits](https://www.conventionalcommits.org/)
   (e.g. `feat(shap): add force plot for single patient`).
3. Open a pull request into `main` using the PR template.
4. Merge with **squash** or **rebase** only. No direct pushes to `main`.

## Notebooks and outputs

- Clear large or noisy cell outputs before committing.
- Save figures used in the slides under `figures/`.
